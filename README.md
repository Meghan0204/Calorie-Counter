# Calorie Counter

A JavaScript calorie tracking project completed as part of the **JavaScript Algorithms and Data Structures Certification** from FreeCodeCamp.org. This project showcases my ability to apply core JavaScript concepts to build an interactive web application.

---

## Overview

This project is a web‑based **Calorie Counter** that allows users to:

- Enter the calories they consume from meals  
- Track total calories logged during a session  
- View running calorie totals as they add or remove entries  

The project demonstrates a practical application of DOM manipulation, event handling, and basic algorithm logic in JavaScript.

---

## Features

✔ Interactive user inputs for calorie entries  
✔ Real‑time calorie total updates  
✔ Ability to add and remove calorie entries  
✔ Simple, clean user interface built with HTML, CSS, and JavaScript  

---

## Technologies Used

- **JavaScript** – program logic and interactivity  
- **HTML5** – page structure and content  
- **CSS3** – styling and layout  

---

## How It Works

The main logic resides in `script.js`, which:

1. Listens for form submissions or button actions
2. Parses user‑entered calorie values
3. Updates totals displayed on the page
4. Reflects changes immediately by updating the DOM

This application emphasizes practical use of arrays, functions, and DOM manipulation in a beginner‑to‑intermediate JavaScript project.
